# 是啊，吃什么

消息包含“吃什么”时，随机推荐食物或回复“是啊，吃什么”。普通情况下默认 70% 推荐、30% 复读；次数保护和复读冷却触发后强制推荐。支持自定义关键词、食物库和食物配图，群聊与私聊均可使用，不依赖聊天模型。

基于 [Sisyphbaous-DT-Project/astrbot_plugin_what_to_eat](https://github.com/Sisyphbaous-DT-Project/astrbot_plugin_what_to_eat) 适配，保留上游 MIT 许可证和作者信息。版本、同类插件调查与修改记录见 [UPSTREAM.md](UPSTREAM.md)。

本适配版本仓库：[MAK1MAAaa/astrbot_plugin_what_to_eat](https://github.com/MAK1MAAaa/astrbot_plugin_what_to_eat)。

## 安装

1. 将本目录复制到 AstrBot 的 `data/plugins/astrbot_plugin_what_to_eat/`，确保 `main.py`、`metadata.yaml` 直接位于该目录。
2. 在 AstrBot 插件管理页重载插件，或重启 AstrBot，启用“是啊，吃什么”。
3. 无额外第三方依赖；需要 Python 3.10+、AstrBot 4.5.7+。WebUI 上传配图另需 AstrBot 支持 `file` 类型配置；旧版可手工放入配图。

本版本沿用上游插件标识。已有同名插件时，先保留原配置和手工 `images/`，再替换对应插件目录；上传数据保存在独立的数据目录中。一次只加载一个同名插件目录。

## 用法

| 消息 | 行为 |
| --- | --- |
| `吃什么`、`今天中午吃什么好？` | 按概率推荐食物或复读。 |
| `/吃什么`、带 @ 的“吃什么”消息 | 消息文字中有关键词即可触发，无需指定前缀。 |
| `吃啥` | 在 `trigger_keywords` 添加“吃啥”后触发。 |
| `1d吃什么还是水饺` | 本合集的 1d 选择插件优先处理，吃什么插件不再重复回复。 |
| 不包含任何配置关键词的消息 | 留给其他插件和框架处理。 |

关键词按文字包含匹配，正则特殊字符也视为普通文字。空关键词会被过滤，列表为空时恢复默认“吃什么”。机器人自身消息会被忽略。命中后停止事件并发送一次文字或图文回复，禁止默认 LLM 再回复。

## 配置

在 AstrBot 插件配置页修改，保存后由框架重载插件。

| 配置项 | 默认值 | 含义 |
| --- | --- | --- |
| `trigger_keywords` | `["吃什么"]` | 任一关键词命中即可触发。 |
| `recommend_probability` | `0.7` | 普通情况下推荐食物的概率，范围 0～1。 |
| `builtin_foods` | 50 项默认食物 | 可自由增删改；显式设置为空列表时保留空库。 |
| `custom_foods` | `[]` | 额外食物，与默认列表合并并去重。 |
| `rate_limit_enabled` | `true` | 启用次数保护，超过阈值后强制推荐。 |
| `rate_limit_max` | `3` | 时间窗口内正常判定的次数，最小为 1。 |
| `rate_limit_window_seconds` | `60` | 滑动时间窗口，单位秒，最小为 1。 |
| `echo_cooldown_enabled` | `true` | 启用复读冷却；与次数保护独立。 |
| `echo_cooldown_seconds` | `15` | 复读后的冷却秒数；0 为关闭，最大为 3600。 |
| `uploaded_images` | `[]` | WebUI 上传的食物图片。 |

默认 60 秒内前三次按概率判定，从第四次起强制推荐。复读后 15 秒内继续触发，也会强制推荐；推荐不会延长复读冷却。每次命中仍然响应消息。

已有安装保留已保存的配置值；要采用新的默认比例，请将 `recommend_probability` 设为 `0.7` 并保存配置。

两个保护开关相互独立。设为 100% 推荐时始终推荐；设为 0% 推荐时，保护规则仍可强制推荐。若希望一直复读，可同时关闭两个保护开关。

食物名称会去除首尾空白、过滤非文字和空项，并按完整名称去重，从合并后的列表等概率选取。推荐分支遇到空库时回复“我想不到推荐什么...你自己决定吧！”。

非法概率使用默认值，有限数值越界时截到 0～1。非整数保护参数使用默认值，整数越界时按表中范围处理。非布尔保护开关使用默认值。

次数与冷却按平台实例、群聊／私聊类型和群 ID／私聊用户 ID 隔离；同一群中的用户共享保护状态。同一事件循环中的复读占位在发送前完成，避免并发连续复读。状态使用单调时间，只保存在内存，过期清理、最多保留 2048 个活跃会话；重载、重启或卸载后重置。

## 食物配图

支持 `jpg`、`jpeg`、`png`、`gif`、`webp`、`bmp`，扩展名忽略大小写。文件名去除扩展名和末尾的数字编号后，与食物名精确对应：

- `水饺.png`
- `水饺_1.jpg`
- `水饺-2.webp`

一个食物有多张图片时随机选一张，与推荐文字合并为一条消息。复读不附图；没有对应图片或图片文件已不存在、不可读取时发送文字。

**WebUI 上传：**在 `uploaded_images` 上传符合命名规则的图片并保存配置。相对路径 `files/...` 从 `data/plugin_data/astrbot_plugin_what_to_eat/` 解析；该目录没有文件时兼容读取上游插件目录中的旧路径。

**手工放图：**在插件目录中创建 `images/`，放入按食物命名的图片，再重载插件。上传与手工图片可同时使用，同一绝对路径只保留一次。

## 验证

从包含本插件目录的根目录运行，需要 Python 3.10+：

```bash
python -B -m unittest discover -s astrbot_plugin_what_to_eat/tests -v
```

也可在本插件仓库目录中运行：

```bash
python -B -m unittest discover -s tests -t .. -v
```

42 项离线测试验证关键词、默认 70% 推荐概率及边界、空食物库、独立开关、滑动窗口、冷却边界、并发占位、会话隔离、图片路径与符号链接、文件缺失、一次回复、发送异常、卸载清理、入口导出和已有 1d 入口优先级。

1d 优先级集成用例需要同目录下的 `astrbot_plugin_1d_choice` 及其测试资源；独立检出本仓库时，该用例自动跳过，其余 41 项仍可运行。

本地未安装 AstrBot，也没有消息平台实例；上述测试使用模拟事件和接口，不代表真实平台已联调。安装后可先设推荐概率为 1，检查文字和上传／手工图片；再设为 0，关闭次数保护，检查连续两次触发依次复读和推荐，以及 15 秒后恢复复读。恢复默认配置后，检查群聊、私聊和 1d 入口的实际表现。
